# State machines with effect-machine

The client's flows move onto [effect-machine](https://github.com/cevr/effect-machine) (pinned at 0.32.1, on our Effect 4.1.4). This file is the plan and the contract. The owner picked the hybrid scope on November 26, 2026.

## The two halves

effect-machine has a transition table (`State`, `Event`, `Machine.make(...).on/.when/.onAny/.immediate/.final`) and an actor that runs it (a mailbox fiber, `task`, `spawn`, `background`, `timeout`). We use the table everywhere a flow has states. We use the actor only where the work is async and nothing deterministic reads its state.

1. **A pure machine on the Model** for every client flow that `update`, the view, a Story, or a recording reads. The Model holds the machine's state. `update` folds each Message through the table with `machineStepOf(machine)` (`src/domain/machines/machineStep.ts`, `Machine.replay` from the state held). A Command or a sound starts on entering a state, chosen by a `$match` on the state entered. This is effect-machine's `.task` on state entry, written as Effect UI Commands so Stories can still resolve them. The first one done is `src/platform/save/linkFlow.ts`.
2. **An actor** for connection work that owns resources and reports Messages: today hand-rolled with `Ref<Option<...>>` handles and Command services. It runs inside a service layer (`Layer.effect` over `Machine.spawn`, scoped), its `.spawn` owning a socket for as long as its state lasts, and its events reach the root through a Subscription over `actor.changes` or a stream it feeds.

**The World is not a machine.** `stepWorld` is a pure 60 Hz tick shared with the co-op room in workerd and with recordings replayed in Bun and Node. Its `Phase` stays a `UiSchema.TaggedEnum` folded by the step: a fold per tick per seat would cost a `runSync` and allocations every frame, against "Keep the frame cheap".

## Rules for a machine

- States and events are effect-machine `State({...})` and `Event({...})`. A state carries only the fields valid in it (`State.X.with(source, partial)` copies shared ones).
- Read a state with `X.$match(state, {...})` (every case) or `X.$is('Tag')(state)` (one check). Empty states are values (`LinkFlow.Idle`), not calls.
- Name guards and handlers with function declarations when the inspector or a test should see them.
- A result event (`GotCode`, `Redeemed`) is accepted only in the state that waits for it. So a late answer after a cancel is dropped by the table, never by a flag.
- Each machine has a coverage test over `Machine.definition(machine)`: the exact list of `state/event` pairs and the `onAny` events, plus a case for each guard. Break the table once to see it fail.
- Handlers are pure. Commands, sounds, focus, and Model fields outside the machine's state are chosen by the root's Step on entry (`enterLinkState` in `src/app/update/profile.ts`).
