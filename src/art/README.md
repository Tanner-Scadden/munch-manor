# `src/art/`

Sprites and pixel art no one feature owns: the atlas, the PNG encoder, the font, the icons.

Every module in this folder has its row below, its path from this folder (`bun run lint` fails a module no row names, and a row naming a file that is gone). Tests are not listed: each sits in the `__tests__/` folder beside the code it tests.

| File                                   | What it holds                                                                                                                                                                                                                                                                                                                                                               |

## `atlas/`

| File                                                | What it holds                                                                                                                                                                                                |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `atlas/spriteAtlas.ts`, `atlas/spritePrecompile.ts` | The prebuilt sprite atlas, content keys, and test stand-ins; the sprites built lazily that the atlas generator must also build                                                                               |
| `atlas/normalMap.ts`                                | A sprite sheet's normal map read off its own pixels (a dome from each shape's edge, lowered where the art is dark), baked with the atlas (`tools/sprites/build.ts`) so the 3D renderer's lights round a body |
| `atlas/spriteAtlasBoot.ts`                          | The prebuilt sprite atlas, in place before the game's modules                                                                                                                                                |
