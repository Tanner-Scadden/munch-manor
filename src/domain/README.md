# `src/domain/`

The client's shared rules and Schemas: what several features (and the client layers) read of a run, the crew, the co-op room, and the player. Each reads the root's Model or a part of it; none names a feature.

Every module in this folder has its row below, its path from this folder (`bun run lint` fails a module no row names, and a row naming a file that is gone). Tests are not listed: each sits in the `__tests__/` folder beside the code it tests.

## At the top

| File                                   | What it holds                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clientSchema.ts`                      | The client's own Schemas no one feature owns (the home menu's state, loading, the bests, a run's records, hints, the tours), re-exported by `app/model.ts`                                                                                                                                                                                                                                            |
| `run.ts`, `onlineRun.ts`               | Where a run stands (home, in a run, an end screen), the rooms opened, the bests it writes, and the feedback ask; what the root, the end card, and the drawing read of an online run: `isRunOn`, its room, the World it left, its difficulty and modifiers, its seats' names and ranks                                                                                                                 |
| `bots.ts`, `coopRoom.ts`               | The lobby's roster rules for teammate bots (add, remove, hero, names, seats, a run's bots); the co-op room as the client holds it: the seam to the World it plays (`coopWorld`), the room's record, co-op's screens, and `maybeRoomOf`                                                                                                                                                                |
| `playerName.ts`, `looks.ts`            | A player's name: its length, cleaning, the co-op join name, and the dice of goofy names; a look's parts and how a chosen word lands on each                                                                                                                                                                                                                                                           |
| `closet.ts`, `unlocks.ts`              | The earned looks' pure rules: a hat, shirt color, print, or gun skin is free, a gift by rank, or bought; its standing and what a pick does; the gifts a rank up opens; the unlocks (gifts and callings) the NEW badges track, and marking them seen when the Look tab or the picker opens                                                                                                             |
| `mastery.ts`                           | Hero and gun mastery's rules: points a wave and a thing, the hero levels and what each opens (a prop style or the Journal's second page), `isStyleOpen`, `fitPropStyle`, the gun skins at 1,000 and 2,500 kills, each track's bar, and what a payout opened                                                                                                                                           |
| `journal.ts`                           | The Dare Journal's client rules: the rooms a run found things in, tallied each frame, what a run adds to the saved journal as it pays out and the milestones it reaches, and the journal's NEW pip (`journal:` unlock ids)                                                                                                                                                                            |
| `dareMarks.ts`                         | The dare ladder on the client: the best mark opened on a difficulty, the pick's next mark, the pick held to what is opened, and an escape opening the next mark (`climbLadder`)                                                                                                                                                                                                                       |
| `beatLink.ts`, `machines/beatMyRun.ts` | Beat my run's Schemas: a friend's dare, its versioned compact `?dare=` code (`dareCodeOf`, `readBeatLink`), `BeatMyRun` (none, offered, taken with the own picks kept), and `isBeaten`; its rules on the root as an effect-machine machine (`beatMachine`, `stepBeat`): offering, taking, releasing, and dismissing a dare, the picks swapped on entering or leaving Taken, the things not yet opened |
| `callingSpecials.ts`                   | Each hero's specials as short lines, read off the rules in `world/heroes/calling.ts`                                                                                                                                                                                                                                                                                                                  |

## `machines/`

| File                                                 | What it holds                                                                                                                                                                                                                         |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `machines/difficultyCard.ts`, `machines/loadFlow.ts` | The first-run difficulty question as an effect-machine machine (`difficultyCardMachine`: unseen, asking with its mode and tutorial pick, seen); the loading splash's (`loadMachine`): a load step finished only while it is waited on |
| `machines/giftFlow.ts`                               | The update gift as an effect-machine machine (`giftMachine`, `stepGift`): wrapped, or unwrapping until the reload                                                                                                                     |
| `machines/machineStep.ts`                            | `machineStepOf(machine)`, an effect-machine `Machine` folded one event at a time as a pure, dual step (`Machine.replay` from the state the Model holds), so `update` keeps the state and stays deterministic                          |
