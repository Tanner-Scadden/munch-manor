# `src/features/`

Client features, one folder per thing on screen: its view, styles, client rules, and Steps. A folder that holds a component (`profile/`, the Profile's `profile/blocks/look/`, `lobby/`, `heroes/`, `munchopedia/`, and `proof/`) uses the component file names ("Folders"); the guide (`guide/`) is a view function, and co-op (`coop/`) is the root's own state with its rules and views.

Every module in this folder has its row below, its path from this folder (`bun run lint` fails a module no row names, and a row naming a file that is gone). Tests are not listed: each sits in the `__tests__/` folder beside the code it tests.
