# `src/render/`

Drawing several features share: the world scene's shapes, its entities, particles, the camera and screen, and the 3D renderer that draws the world (`iso/`).

Every module in this folder has its row below, its path from this folder (`bun run lint` fails a module no row names, and a row naming a file that is gone). Tests are not listed: each sits in the `__tests__/` folder beside the code it tests.

## At the top

| File                     | What it holds                                                                                                                                                                                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `draw.ts`                | The game's drawing vocabulary as plain data: rects, circles, paths, images, and groups (`Draw.Shape`), built by the art modules and drawn by Pixi alone                                                                                                                                                                  |
| `renderSchema.ts`        | The cosmetics the Model keeps for drawing: particles, decals, and what the hero tells saw last frame                                                                                                                                                                                                                     |
| `depth.ts`, `drawing.ts` | The foot-depth sort, the furniture's carve depth (`TALL_MOST`) and how much nearer what is drawn on a carved piece stands (`IN_FRONT_PX`), and the shape helpers shared by the world views                                                                                                                               |
| `pixelCircle.ts`         | Circles on the game's pixel grid: a disc or a closed ring of whole pixels as rows of spans, baked once per size and color as a sprite (`pixelRing`, `pixelDisc`, baked as a module loads by `bakeRings` and `bakeDiscs`), or drawn as its spans (`pixelRingSpans`, `pixelDiscSpans`) when too wide to bake at every size |

## `iso/`

| File                                           | What it holds                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `iso/element.ts`, `iso/frame.ts`               | `<munch-world>`, the 3D renderer on the page: the view sets its `frame` each render and it draws that frame then and there (but a held one), loading the renderer in its own chunk; the `IsoFrame` it draws (the Model, the world's strata, the game's camera and shake, the sprites to load ahead, the hold key)                                                                  |
| `iso/overlayElement.ts`, `iso/overlayScene.ts` | `<munch-overlay>`, the HUD, the banners, and the cards over the world on the page: the view sets its `picture` each render and it paints only a picture that differs, loading the renderer in its own chunk; `OverlayScene`, the overlay's renderer, painting `Draw` shapes flat with Pixi on a WebGL canvas of one canvas pixel to a game pixel, stretched by CSS, with no ticker |
| `iso/hold.ts`                                  | The world's picture held while the World stands still (a paused run, an end card once its beat settles): a frame's hold key, every input its picture is drawn from, and `isHeldOver`, whether a frame shows the picture last drawn, so a menu's own frames draw no 3D                                                                                                              |
| `iso/support.ts`, `iso/scene.ts`               | Whether this device can draw the world (WebGL2), and the page a device that can't sees; `IsoScene`, the PixiJS 3D renderer: the camera on the game's lens, the floor layers, what stands, what floats, the lights, the muzzle flash, the tracers                                                                                                                                   |
| `iso/lensCamera.ts`                            | The 3D renderer's camera set from the game's lens: the lens's frame on the 3D canvas, less the shake, and the pixi camera standing, looking, and seeing as the lens does                                                                                                                                                                                                           |
| `iso/cull.ts`                                  | What the camera sees of the house, and whether a thing lies near enough to it to matter: the furniture, ferns, and their shadows far off screen are left out of the frame; the floor seen as the lens's true quad (`viewFloorOf`), and a room light casting only while its pool lies on it (`isOnFloorSeen`)                                                                       |
| `iso/space.ts`, `iso/flatten.ts`               | Game pixels as 3D units: the camera's pitch, the stretch that keeps the floor on the game's map, a wall's face a row of its art a screen pixel (`WALL_ROW`), a tall wall's nine rows and a low front wall's two; Canvas shapes flattened into leaves with their transforms and alpha                                                                                               |
| `iso/painter.ts`, `iso/textures.ts`            | Canvas shapes painted flat into pixi, the floor's pictures in coats, and the planes that show them (one lit plane for the room, decals, and what has landed; one for what glows); each sprite source loaded once, its crops, silhouettes, and shadow materials                                                                                                                     |
| `iso/tunable.ts`                               | `Tunable`, a table the renderer reads by identity each frame, shipped as written and swapped only by Munch Studio's light and color lab                                                                                                                                                                                                                                            |
