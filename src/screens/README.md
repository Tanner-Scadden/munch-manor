# `src/screens/`

Screens that put several features together, one folder per screen. A screen imports any feature and any lower layer, never another screen and never `app/`.

Every module in this folder has its row below, its path from this folder (`bun run lint` fails a module no row names, and a row naming a file that is gone). Tests are not listed: each sits in the `__tests__/` folder beside the code it tests.

## `game/`

| File                                     | What it holds                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `game/worldView.ts`, `game/overlay.ts`   | The game surface's canvases: the world scene, the room, its entities, and the features' art in the foot-depth sort; the overlay: title, banners, pause, hints, and stats panels                                                                                                                                                          |
| `game/hud.ts`, `game/stallBubble.ts`     | The HUD: hearts, the crew's key ring, the streak, gun and trap slots, the big key count, the round text, the dare pocket, and the couch's rows; Rattles' speech bubble, from the spot it is about or his own (`rattlesSpot`), pinned to the edge out of view: the kitchen's holler, his dare hints, and the tour's marks                 |
| `game/pocket.ts`                         | Whether the dare pocket is open on the whole list (in a break, the card put away or folding, no banner in its rows) or shut, and every HUD button and panel over the window (`hudKeepoutsOf`: the pocket, the key ring and hearts, the corner button, START WAVE, the gun slots) for Rattles' bubbles and the shop's tags to keep out of |
| `game/dareListButton.ts`                 | The HUD's dare list as a clear button over the pocket the canvas draws, opening the dare card again and putting it away                                                                                                                                                                                                                  |
| `game/touchControls.ts`, `game/menus.ts` | The touch controls: sticks, ghost sticks, the gun cluster, and icon buttons; the buttons over the game: the corner's (with the pause MENU pill), the end card's, and the new zombie card                                                                                                                                                 |
| `game/endMissions.ts`                    | The day's missions on the end card, placed beside it on a screen on its side and under it upright, after the rank strip's beat                                                                                                                                                                                                           |
